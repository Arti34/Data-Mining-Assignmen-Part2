# Instructor / Self-study Guide

## Suggested sequence

- Session 1: Business Understanding + Data Understanding
- Session 2: Data Preparation + EDA
- Session 3: Clustering + Anomaly Detection
- Session 4: Supervised Learning + Leakage
- Session 5: Association Rules + LSH
- Session 6: Evaluation + Synthesis

## Discussion prompts

1. Propose a different business target using the same raw data.
2. Should cancellations be removed, modeled, or both?
3. Compare random splitting with temporal splitting.
4. Name a business anomaly that may not be a statistical anomaly.
5. Change association thresholds and discuss coverage versus specificity.
6. Change LSH bands and observe candidate retrieval.
7. Write one recommendation and one limitation for every model.

## Assessment rubric

| Dimension | Excellent |
|---|---|
| Business framing | Clear decision, stakeholder, KPI, and success criteria |
| Data understanding | Evidence-based audit and explicit assumptions |
| Preparation | Reproducible, justified transformations |
| Modeling | Method clearly tied to question |
| Evaluation | Multiple metrics plus business interpretation |
| Communication | Clear synthesis, limitations, and next steps |
